# homebrew-nox

```bash
brew tap noxhsxrk/nox
brew install alias-manager-script
```

## Shaken

[Shaken](https://shaken.noxhsxrk.com/) is a menu-bar app for macOS: shake while dragging to open a wheel of commands.

```bash
brew install --cask noxhsxrk/nox/shaken
```

It opens on first launch without the Gatekeeper prompt, and updates itself from *Help › Check for Updates*.
